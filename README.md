## The word

> **rebye:** the second goodbye you say to someone you have only just said goodbye to.

Everyone knows the moment: you say goodbye at the door, then meet the same
person again in the lift, on the stairs, at the gate — and you have to say
goodbye a second time. English has no word for that second goodbye. **rebye**
fills the gap: short, sayable, spellable, and built the way English builds
words (`re-` + `bye`).

## How it works

`main.py` writes the coined word and its one-line definition to
`/output/entry.txt` — exactly 80 characters, one line, no trailing newline.
It validates the line strictly against the competition gate first (1–140
characters, not only whitespace, single line, no control characters).

```sh
python3 main.py              # write the entry to /output/entry.txt
python3 main.py --self-test  # run the gate-validation test suite
```
